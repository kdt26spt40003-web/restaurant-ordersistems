# restaurant-ordersistems

洋食レストラン「ひだまり亭」の注文システム（Python / tkinter）。
標準ライブラリだけで動くので、追加インストールは不要です。

## 起動方法

```
py main.py
```

（`python main.py` でも可。Python 3.10 以上）

## 機能

| 要件 | 内容 |
| --- | --- |
| 店名表示 | 起動時にスプラッシュ画面で店名を表示。画面上部にも常に表示 |
| メニュー表示 | 27 品。「すべて／前菜／メイン／ご飯・パスタ／ドリンク／デザート」のボタンで表示を切り替え |
| 注文 | 料理を選び、数量（1〜99）を指定して「注文する」（ダブルクリックでも可） |
| 注文取消 | 会計前なら「ご注文内容」から選んで「選択した注文を取り消す」（Delete キーでも可） |
| 注文データの記録 | 注文・取消・会計を `order_log.csv` に 1 行ずつ追記（伝票番号つき） |
| 注文履歴 | 画面右上の「注文履歴」で、過去の伝票を新しい順に一覧表示。選ぶと注文・取消・会計の明細が見られる。会計済の件数と売上合計も表示 |
| アレルギー対応 | 全品に特定原材料 8 品目（卵・乳・小麦・えび・かに・そば・落花生・くるみ）を表示。お客様のアレルギー食材を選ぶと、該当料理に ⚠ を付けて赤字表示（「表示しない」にすると非表示）。該当料理を注文しようとすると確認が出る。会計後は設定をリセット |
| おすすめ | 年齢・性別・気分から前菜／お食事／ドリンク／デザートを 1 品ずつ提案。20 歳未満にはお酒を、アレルギー食材を含む料理は出さない |
| 会計 | 「お会計」ボタンで明細と合計金額（税込）を表示し、確定すると次の伝票へ |
| 入力チェック | 年齢に文字・負の数・小数・空欄・121 以上を入れても、警告を出すだけで停止しない（全角数字は受け付ける）。数量も同様 |

## ファイル構成

- `main.py` … 画面（tkinter）
- `menu.py` … 店名・メニューと価格
- `order.py` … 注文の追加・取消・会計と CSV への記録
- `recommend.py` … 年齢の入力チェックとおすすめロジック
